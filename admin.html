Cloud Sync (simpan lintas perangkat)

Isi URL Firebase Realtime Database supaya data & foto profil sama di HP dan komputer. Panduan singkat ada di bawah form.

Cara setup gratis (sekali saja):
1. Buka console.firebase.google.com
2. Create project → Build → Realtime Database → Create Database → Start in test mode
3. Copy URL database (contoh: https://xxx-default-rtdb.asia-southeast1.firebasedatabase.app)
4. Paste di atas → Simpan Semua
5. Rules test mode biasanya aktif 30 hari; untuk portfolio pribadi bisa set read/write true
