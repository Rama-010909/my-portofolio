CARA PASANG LAGU "About You - The 1975"
========================================

1. Download lagu About You dari sumber legal (Spotify download untuk offline, 
   beli di iTunes, dll) — jangan pakai file bajakan.

2. Rename file jadi:  about-you.mp3

3. Taruh file about-you.mp3 di folder yang sama dengan index.html
   (folder portfolio-website/)

4. Buka index.html → klik tombol play di kiri bawah.

Catatan: Browser modern sering memblokir autoplay.
Lagu hanya mulai setelah kamu klik tombol play.
